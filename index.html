Часті питання (FAQ)

Який програвач використовується і як підключити комп'ютер до телевізора (кабелі чи Wi-Fi)?

Комплекс розроблено для комп'ютерів та ноутбуків під керуванням Windows 10/11 на базі найкращого класичного програвача MPC-HC (Media Player Classic Home Cinema), який вже входить в інсталятор. Всередину самого телевізора (Smart TV) програма не ставиться, адже нейромережа RIFE AI використовує потужність відеокарти ПК.

Як вивести картинку з ПК/ноутбука на телевізор:
• По кабелю (максимальна якість 60–144 Гц без затримок): через кабель HDMI, DisplayPort або USB Type-C (Thunderbolt).
• Бездротово по Wi-Fi (5 ГГц / Wi-Fi 6): через функцію бездротового дисплея Windows (клавіші Win + K / Miracast) або високочастотні системи стримінгу Moonlight / Steam Link. (Примітка: Bluetooth передає лише звук, для відео використовуйте кабель або Wi-Fi).

Чи навантажує програма комп'ютер, коли я не дивлюся відео?

Ні, абсолютно 0% навантаження! Модуль TALOS працює виключно в момент відкриття відеофайлу у плеєрі MPC-HC. Щойно ти закриваєш плеєр — пам'ять та відеокарта миттєво звільняються.

Чи потрібно мені щось налаштовувати вручну після встановлення?

Ні. Інсталятор автоматично встановлює плеєр MPC-HC, бібліотеки та прописує всі 54 параметри DirectShow-фільтра у Реєстр. Ти просто відкриваєш будь-який фільм — і він одразу йде у 60–144 FPS.

Чим це краще за російський SVP 4?

1) Повністю українська автономна розробка без фонових служб телеметрії. 2) Чесний Цілий Автомножник (x2 = 48 FPS для кіно 24 к/с та 60 FPS для 30 к/с) зберігає 100% оригінальних кадрів без ефекту «желе», ореолів та мікрофрізів, які виникають у SVP при дробовому множнику x2.5. 3) З коробки увімкнено чисту нейромережу RIFE v4.6 для 1080p/4K без прихованих блокувань.

На скільки пристроїв діє ліцензія, що робити при перевстановленні Windows і як працює знижка -50% на планшет?

1) Прив'язка до заліза (1 Ліцензія = 1 Пристрій): Кожна придбана копія активується на одному обраному пристрої (HWID) і назавжди прив'язується до вашої електронної пошти (Email) у базі покупців.
2) Безкоштовне відновлення при перевстановленні ОС: Відразу після оплати на вашу пошту надходить лист-квитанція з безстроковою кнопкою завантаження. При перевстановленні Windows на тому самому ПК ваша ліцензія зберігається довічно.
3) Спеціальна акція «1 ПК (100%) + 1 Планшет (-50%)»: Для покупців, які вже придбали повну ліцензію за 100% на свій основний ПК або ноутбук, діє право оформити 1 додаткову ліцензію TALOS LITE зі знижкою -50% виключно для особистого планшета на базі Windows 10/11!
